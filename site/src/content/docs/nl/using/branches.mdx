**Branches** in de zijbalk (⌘3) toont de branches van de repositories die je volgt als boom: per repository bovenaan de standaardbranch, en elke andere branch onder de branch waar hij van gemaakt is. ## De boom

Elke repository is een groep die je met een klik op de naam dichtklapt; ernaast staat hoeveel branches vandaag een push kregen. Daaronder:

- De standaardbranch, met **standaard** erbij.
- Elke branch onder de branch waar hij van gemaakt is, zo diep als nodig. De recentste push staat bovenaan.
- **Wie**: wie het laatst pushte, met foto. Klik op een naam om alleen diens branches te zien.
- **Voor / achter**: ↑3 ↓1 betekent drie commits die de ouder niet heeft, en één commit van de ouder die deze branch nog niet heeft.
- **Laatste push**, met een stip als die in het afgelopen uur was.
- Een pill met het nummer van een open pull request, en **Nieuwe branch** of **Force-push** als dat de afgelopen dag gebeurde.

## Hoe Pullwatch weet waar een branch vandaan komt

Git en de diensten houden niet bij van welke branch een branch gemaakt is. Pullwatch zoekt het uit in deze volgorde:

1. De doelbranch van een open pull request vanaf de branch.
2. Anders de geschiedenis: de branch waar hij de minste commits voor ligt, zoals Git het zelf voorstelt.
3. Anders de standaardbranch.

Het inspectievenster zegt welke van de drie het werd. Het uitzoeken kost een paar verzoeken per nieuwe branch, dus bij een repository met veel nieuwe branches duurt het soms een paar keer lezen voordat alles op zijn plek staat; tot dan hangt zo'n branch onder de standaardbranch.

## Het inspectievenster

Kies een branch om hem rechts te zien: het pad vanaf de standaardbranch, **Vergelijk met ouder** (de vergelijking bij de dienst), **Open in browser** en **Kopieer branchnaam**. Daaronder **Gemaakt van** met hoe Pullwatch dat weet, hoe ver de branch van zijn ouder en van de standaardbranch afstaat, zijn pull request en de laatste push. **Activiteit** toont de pushes die Pullwatch zag; elke push opent zijn vergelijking.

Pullwatch ziet wat er tussen twee keer lezen veranderde, niet elke losse push. Drie pushes tussen twee keer lezen zijn één regel met alle nieuwe commits.

## Zoeken en filters

Zoek op branch, repository of persoon. De knoppenbalk filtert op een repository of een persoon; **Alleen anderen** verbergt de branches waar jij het laatst op pushte. Een branch die gevonden wordt houdt de branches erboven, zodat je blijft zien waar hij hangt.

**Verwijderde branches** toont ook branches die gemerged of weggehaald zijn, gedimd en doorgestreept, zolang de geschiedenis bewaard wordt. **Laad opnieuw** leest de branches meteen; de ondertitel zegt wanneer ze het laatst gecheckt zijn.

Pullwatch herkent je eigen pushes aan je account op GitHub, en op Bitbucket en Gitea waar het account aan de persoon gekoppeld is. Anders vergelijkt het de naam en het e-mailadres van de auteur met de jouwe.

## Geen meldingen

Pushes geven nooit een melding, tellen niet mee als ongelezen en staan niet in het menupaneel of op de Dock-badge. Dit is een lijst om in te kijken, geen stroom om bij te houden.

## Branches volgen

Branches volgen mee met pull requests, per repository: vink je **PR's** aan voor een repository, dan staat **Branches** ook aan, en haal je het vinkje bij **PR's** weg, dan gaan ze allebei uit. Wil je alleen de branches van een repository uitzetten, haal dan het vinkje bij **Branches** weg in de lijst met repositories van het account (Instellingen, Accounts) of onder **Volgen** op het **Overzicht** van de repository. Zolang de lijst nog leeg is, heeft het onderdeel een knop **Branches volgen** die Instellingen, Accounts opent.

Branches worden hooguit elke 15 minuten gelezen, los van pull requests en tags. Een rate limit op branches houdt pull requests of tags nooit tegen: die komen zoals altijd binnen, en branches wachten tot de limiet voorbij is. Pushes blijven bewaard zo lang als de geschiedenis (Instellingen, Algemeen, **Geschiedenis bewaren**).
